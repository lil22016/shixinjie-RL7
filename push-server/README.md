# 拾心界：离线推送服务（替代后台音频保活）

这是一个免费的 Cloudflare Worker。它只做一件事：**到了「主动发送间隔」就给手机发一条 Web Push，把网站叫醒**。
具体发什么由手机上的 `sw.js` 从你的字卡里随机抽，服务器不保存任何聊天内容、字卡或账号信息，只保存「推送地址 + 下次发送时间」。

## 一次性部署（全程网页操作，约 10 分钟）

### 1. 准备 VAPID 密钥
VAPID 是推送服务的「身份证」，一对公钥 + 私钥。
- 有 Node.js 的话：在 `push-server` 目录运行 `node gen-vapid.mjs`，会打印两行。
- 没有的话：直接用随本次修改一起给你的 `vapid-keys.txt`。

**私钥不要提交到 GitHub。**

### 2. 在 Cloudflare 创建 Worker
1. 注册/登录 https://dash.cloudflare.com （免费套餐即可）。
2. 左侧 **Workers 和 Pages** → **创建** → **导入存储库（Import a repository）** → 连接 GitHub，选 `lil22016/shixinjie-RL7`。
3. 构建设置里 **根目录（Root directory）填 `push-server`**，其他保持默认，点部署。
   它会自动读取 `wrangler.toml`，创建名为 `shixinjie-push` 的 Worker 和它需要的 Durable Object。
4. 部署完成后进入这个 Worker → **设置 → 变量和机密**，添加两个 **机密（Secret）**：
   - `VAPID_PUBLIC_KEY` = 第 1 步的公钥
   - `VAPID_PRIVATE_KEY` = 第 1 步的私钥
5. 记下 Worker 地址，形如 `https://shixinjie-push.<你的子域>.workers.dev`。
   浏览器打开 `该地址/api/health`，看到 `"vapid":true` 就说明好了。

> 如果你的网站不是 `https://lil22016.github.io`，改一下 `wrangler.toml` 里的 `ALLOWED_ORIGINS`。

### 3. 让网站连上推送服务
打开 `js/rl7-v91-web-push.js`，把开头第 14 行
```js
var PUSH_SERVER = 'https://YOUR-PUSH-SERVICE.workers.dev';
```
改成第 2 步的地址（末尾不要加 `/`），提交到 GitHub。

### 4. 在手机上开启
- **iPhone**：必须 iOS 16.4 以上，并且先用 Safari「分享 → 添加到主屏幕」，**从主屏图标打开**网站（Safari 标签页里没有推送功能）。
- **安卓**：Chrome 里直接用即可，建议也添加到主屏幕。

然后：聊天设置 → 后台 → 打开 **离线推送（无需保活）** → 允许通知 → 点「发送测试推送」，锁屏看能不能收到。
收到后就可以把 **后台保活** 关掉了。前提是「主动发送」是开着的。

## 工作原理
| 网站状态 | 谁负责发消息 |
| --- | --- |
| 在前台 | 和以前一样，网页自己的计时器（每 5 分钟告诉服务器“我在前台，先别推”） |
| 切到后台 / 锁屏 / 被系统杀掉 | 服务器按间隔发推送 → `sw.js` 抽字卡、弹通知、存进队列 |
| 再次打开 | 队列里的消息自动写进聊天记录，和平时收到的一样 |

## 已知限制
- 后台推送出来的是**普通文字字卡**（含拼字卡、emoji / 颜文字混入）。红包、表情包、语音、拍一拍、撤回、来电等需要完整网页才能做的花样，只在前台发生。
- 发送对象是「主动发送」当前目标的单聊；群聊在后台不推送。
- 后台用的是你**最后一次打开网站时**的字卡快照；改了字卡后打开一下网站就会更新。
- iOS 的「专注模式」「通知摘要」会延迟或合并通知，这是系统行为。
- 如果在手机设置里关掉了网站通知或删除了主屏图标，订阅会失效，服务器会自动清理；重新开启开关即可。
- 免费套餐额度足够个人使用（每天几万次请求 / Durable Object 写入）。
